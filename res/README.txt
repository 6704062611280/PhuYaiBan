โฟลเดอร์ res = ของที่เกมโหลดเอง (ไฟล์ไหนไม่มีก็ได้ เกมจะใช้ของในตัวแทน)

levels/level1.txt, level2.txt   แผนที่ด่าน (วิธีเขียนอยู่ในหัวไฟล์)
    ตัวอักษร:  # บล็อกตัน   = แพลตฟอร์มบาง   P จุดเกิด   G ธงปลายทาง
               W ศัตรูเดิน   F ศัตรูบิน      T แท็งก์     H ไอเท็มฮีล
    - ค่าในหัวไฟล์: name, theme (day/night), difficulty (ตัวคูณความเก่งศัตรู), walker_reflect (on/off = ศัตรูเดินยกโล่สะท้อนกระสุนได้ไหม)
    - เพิ่มด่านใหม่: สร้างไฟล์ใหม่ แล้วเติมชื่อไฟล์ใน LEVEL_FILES ที่ GamePanel.java
    - ระหว่างเล่น (รันจาก VS Code) แก้ไฟล์แล้วกด F5 เพื่อโหลดด่านใหม่ทันที

images/   สไปรต์ทั้งหมดเป็นแผ่นเฟรมเรียงแนวนอน (sprite sheet) วาดให้ตัวละครหันขวา เกมพลิกซ้ายให้เอง
          PNG พื้นโปร่งใส ถ้าอยากเปลี่ยนเป็นรูปของตัวเอง ให้ใช้ขนาดเฟรมและลำดับเฟรมตามนี้
    player.png   (ผู้ใหญ่บ้าน) เฟรมละ 40x60   7 เฟรม = 0-1 ยืนนิ่ง, 2-5 วิ่ง, 6 กระโดด  (ไม่ต้องวาดปืน เกมวาดปืนหมุนตามเมาส์ให้)
    walker.png   (ผีผ้าขาว) เฟรมละ 40x50   2 เฟรม = เดิน
    flyer.png    (ผีกระสือ) เฟรมละ 44x30   2 เฟรม = ปีกขึ้น, ปีกลง
    tank.png     (ผีตาโขน) เฟรมละ 56x70   4 เฟรม = 0-1 เดิน, 2 เตรียมพุ่ง, 3 พุ่ง
    heal.png     (ดอกบัว) 24x24          1 เฟรม
    - รูปเดี่ยวขนาดอื่น (ไม่ใช่แผ่นเฟรม) ก็ใช้ได้ เกมจะใช้เป็นเฟรมเดียวและย่อ/ขยายให้พอดีตัวละคร
    - ลบไฟล์ไหนทิ้ง = ตัวละครนั้นกลับไปใช้สี่เหลี่ยมสีแทน

sounds/<ชื่อ>.wav   ใส่ไฟล์เพื่อแทนเสียงสังเคราะห์ ชื่อที่ใช้ได้:
    shoot  jump  dash  hit  enemy_die  hurt  click  level_clear  game_over  win  pickup  reflect
    (ควรเป็น WAV 16-bit PCM)

tools/make_sprites.py  สคริปต์ Python (ต้องมี Pillow) ที่วาดสไปรต์ทั้งหมด: python make_sprites.py <โฟลเดอร์ปลายทาง> <พรีวิว.png>
